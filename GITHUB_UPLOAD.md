# Upload to GitHub Pages

1. Extract this ZIP.
2. Upload the files **inside** this folder to the root of the `allocator` repository's `main` branch.
3. Confirm `index.html`, `app.js`, `style.css`, and `.nojekyll` are at repository root.
4. GitHub → Settings → Pages → Deploy from a branch → `main` → `/(root)`.
5. After the site updates, confirm the footer says **Static Pages build v10**.
6. Redeploy `apps-script/Code.gs` as a new Apps Script Web app version.
7. Connect the `/exec` URL, then click **Test Sheet Write**.
